## 方案决策

采用新轻量 relay，避免将账户/多租户/好友/数据库继续带入单用户系统。文件只在端点保存；普通 WS 故障由 outbox/inbox+receipt 重传处理，业务提交以单独 ack 确认；旧数据库恢复使用 epoch/incarnation 门禁。云中继暂用单实例，重启可重连但不会提供跨区域容灾承诺。

用户确认原图“本地保留，可手动删除”。已删除文件保留内容摘要和审计墓碑，原图不因识别成功自动删除。

## 检查范围

- 架构：当前文档、原型、schema 全部指向 v2；旧方案明确归档。
- 协议：命令/回执关联、持久确认、重复/丢失/断线、会话替换、恢复隔离、文件并发与取消。
- 量化/AI：源码证据、时点与泄漏、交易日、可成交性、回测与实际记录口径、风控与来源审计。
- App：13屏/5Tab保留，字号、48dp触控目标、对比度、状态反馈、隐私与通知降级；静态检查与真实渲染分开。
- 校验：schema/正反样例/摘要/故障参考模型、链接/HTML/JS；真实三端联调留给实现阶段。
